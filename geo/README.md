# GEO / AEO — สิ่งที่เราทำ และสิ่งที่เราตรวจแล้วว่าไม่จริง

> **GEO (Generative Engine Optimization)** คือการทำให้ผู้ช่วย AI หยิบเนื้อหาของเราไปใช้ตอบคำถามคน
> **AEO (Answer Engine Optimization)** คือการเขียนเนื้อหาให้ตอบคำถามจบในตัวเอง จนเครื่องยกไปใช้ได้ทั้งประโยค
>
> หน้านี้เปิดเผยวิธีที่เราทำจริง **พร้อมแหล่งอ้างอิงและวันที่ที่เราเปิดอ่าน** เอาไปใช้ได้เลย (CC BY 4.0)

## 🔴 ข้อเท็จจริงที่เราไปเปิดเอกสารทางการอ่านเอง

วงการ GEO เต็มไปด้วยคำแนะนำที่ไม่มีใครตรวจ · ห้าข้อนี้เราเปิดหน้าทางการอ่านเองเมื่อ **17 กันยายน 2026**

| ข้ออ้างที่ได้ยินบ่อย | สิ่งที่เอกสารทางการเขียนจริง |
| --- | --- |
| "ต้องใส่ schema พิเศษ AI ถึงจะหยิบไปตอบ" | ❌ **ไม่จริง** — Google เขียนว่าหน้าต้อง *"indexed and eligible to be shown in Google Search with a snippet"* เท่านั้น **ไม่ต้องมี schema, markup หรือไฟล์ AI พิเศษใดๆ รวมถึง `llms.txt`** ([Google Search Central, อัปเดต 2025-12-10](https://developers.google.com/search/docs/appearance/ai-features)) |
| "ทำ FAQ schema แล้วจะได้กล่องคำถามในผลค้นหา" | ❌ **เลิกแสดงแล้ว** — Google เลิกแสดงกล่อง FAQ กับทุกเว็บตั้งแต่ **7 พฤษภาคม 2026** · ทิ้ง markup ไว้ได้ ไม่เสียหาย แต่จะไม่แสดงผล |
| "ChatGPT ใช้ดัชนีของ Bing ไม่ใช่ Google" | ⚠️ **ยืนยันไม่ได้** — OpenAI บอกแค่ว่าใช้ *"third-party search providers"* · การทดลองของ Semrush (ส.ค. 2025) พบว่าบางครั้งใช้ผลของ Google ด้วย → **อย่าวางแผนโดยเชื่อว่าเป็น Bing อย่างเดียว** |
| "`llms.txt` ทำให้ AI อ่านเว็บเราได้" | ⚠️ **ยังไม่มีใครยืนยัน** — ยังไม่พบผู้ให้บริการ AI รายไหนประกาศว่าอ่านไฟล์นี้ตอนหาคำตอบ · เราทำไว้เพราะต้นทุนต่ำ ไม่ใช่เพราะมีหลักฐานว่าได้ผล |
| "วัดผล GEO ได้จากเครื่องมือสำเร็จรูป" | ⚠️ **ตรวจคำตอบจริงก่อนเชื่อตัวเลขเสมอ** — เราเคยเจอรายงานขึ้น *"ถูกเอ่ยชื่อ 9 ครั้ง ส่วนแบ่ง 100% อันดับ 1"* ทั้งที่**คำตอบจริงไม่มีชื่อเราสักครั้ง** เพราะชื่อเรียกแบรนด์ที่ตั้งไว้ดันมีคำว่า "Shopee" ปนอยู่ |

🔵 **Bing Webmaster Tools มีรายงาน AI Performance** (public preview 10 ก.พ. 2026) — นับจำนวนครั้งที่ Copilot
และสรุป AI ของ Bing อ้างเว็บเรา และคำที่ AI ใช้ค้น · เป็นตัวเลขฝั่ง AI ที่หาได้ฟรีที่สุดเท่าที่เรารู้จัก

## ลำดับที่เราทำ — เรียงตามผลจริง ไม่ใช่ตามความยาก

### 1. ติดดัชนีก่อน ทุกอย่างที่เหลือไม่มีความหมายถ้าข้อนี้ไม่ผ่าน

หน้าที่ไม่อยู่ในดัชนี ไม่มีทางถูกหยิบไปตอบ — เอกสารของ Google เขียนไว้ตรงๆ
**ทำทั้ง Google Search Console และ Bing Webmaster Tools** เพราะยืนยันไม่ได้ว่าผู้ช่วย AI แต่ละเจ้าใช้ดัชนีไหน

### 2. ชื่อหน้าต้องมีคำที่คนพิมพ์จริง

ไม่ใช่คำที่เราคิดว่าคนพิมพ์ · คำค้นจริงหาได้จาก Search Console และ Bing Webmaster Tools โดยไม่ต้องจ่ายเงิน

### 3. ให้มีคนพูดถึงเรานอกเว็บตัวเอง

**นี่คือข้อที่ทำยากที่สุด และเป็นเหตุผลที่ที่เก็บนี้มีอยู่** — ข้อมูลที่อยู่แต่บนโดเมนตัวเอง
เป็นแหล่งเดียว ไม่มีอะไรยืนยัน · การมีข้อเท็จจริงชุดเดียวกันอยู่หลายที่ **ในชื่อเดียวกันและเชื่อมถึงกันได้**
ทำให้เครื่องเห็นว่าเป็นตัวตนเดียว ไม่ใช่หลายเจ้าที่บังเอิญชื่อคล้ายกัน

### 4. ผูกตัวตนด้วย `sameAs`

ประกาศให้เครื่องรู้ว่าเว็บ เพจ ช่อง และที่เก็บนี้คือเจ้าของเดียวกัน → [`../data/organization.jsonld`](../data/organization.jsonld)
เป็นสัญญาณที่**ราคาถูกที่สุดและคนลืมใส่บ่อยที่สุด**

### 5. เขียนแบบ AEO — ประโยคแรกต้องตอบจบ

กฎเดียวที่เราบังคับตัวเองทุกหน้า: **ประโยคแรกของคำตอบต้องอ่านแล้วจบ โดยไม่ต้องอ่านย่อหน้าที่เหลือ**
เพราะนั่นคือประโยคที่เครื่องยกไป · ดูตัวอย่างที่ [`../faq.md`](../faq.md)

### 6. เขียนภาษาไทยด้วย ไม่ใช่อังกฤษอย่างเดียว

🔴 **บทเรียนของเราเอง:** `llms.txt` ฉบับแรกของเราไม่มีคำไทยเลยสักคำ เพราะดึงแต่เนื้อหาภาษาอังกฤษ
แปลว่าคนที่ถาม AI **เป็นภาษาไทย** ไม่มีข้อความไทยในไฟล์นั้นให้จับคู่เลย ทั้งที่ไทยคือตลาดหลักของเรา
· แก้เมื่อ 6 กันยายน 2026

## ✅ รายการตรวจ — เอาไปใช้กับเว็บของคุณได้เลย

- [ ] หน้าสำคัญทุกหน้าอยู่ในดัชนีของ **ทั้ง Google และ Bing** (ไม่ใช่แค่ส่งแผนผังเว็บแล้วถือว่าจบ)
- [ ] `sitemap.xml` และ `robots.txt` ตอบ 200 และตรงกับหน้าที่มีอยู่จริง
- [ ] การ์ดองค์กรมี `sameAs` ครบทุกช่องทางที่เป็นของเรา
- [ ] **ทุกหน้าที่ตอบคำถาม ประโยคแรกตอบจบในตัวเอง**
- [ ] มีเนื้อหา**ภาษาไทย**ให้จับคู่ ไม่ใช่อังกฤษอย่างเดียว
- [ ] ตัวเลขทุกตัวที่เขียนไว้ **สร้างจากระบบจริง** ไม่ใช่พิมพ์มือที่จะเก่าลงเงียบๆ
- [ ] เขียนไว้ชัดว่า**อะไรอ้างอิงได้และอะไรอ้างอิงไม่ได้** (ดู [`../README.md`](../README.md))
- [ ] มีสัญญาอนุญาตที่อนุญาตให้นำไปใช้ต่อได้ (เราใช้ CC BY 4.0)
- [ ] ข้อเท็จจริงชุดเดียวกันอยู่มากกว่าหนึ่งที่ **ในชื่อเดียวกันและลิงก์ถึงกัน**
- [ ] **เปิดคำตอบจริงของ AI ดูด้วยตา** ก่อนเชื่อรายงานของเครื่องมือวัดใดๆ

| ไม่ทำ | เพราะ |
| --- | --- |
| เขียนรีวิวลูกค้า กรณีศึกษา หรือจำนวนผู้ใช้ | **เรายังไม่มีสักราย** · ตัวเลขปลอมที่ AI หยิบไปตอบ คือคำโกหกที่แพร่ไปโดยไม่มีใครเห็นว่ามาจากไหน |
| เขียนตัวเลขด้วยมือในหน้าที่ลูกค้าอ่าน | มันเก่าลงเงียบๆ · ตัวเลขของเราสร้างจากฐานข้อมูลวันละครั้ง |
| ซ่อนข้อจำกัดของสินค้า | เราเขียน "ยังไม่มีนางแบบไซซ์ใหญ่" และ "ยังทำวิดีโอไม่ได้" ไว้ในหน้าที่ AI อ่าน เพราะคนที่ถาม AI แล้วได้คำตอบตรง เสียเวลาน้อยกว่าคนที่สมัครแล้วมาพบทีหลัง |
| คัดลอกบทความจากเว็บมาไว้ที่นี่ | เนื้อหาซ้ำแข่งกับหน้าต้นฉบับของเราเอง · ที่เก็บนี้จึงมีแต่**ข้อมูลที่เครื่องอ่าน** ส่วนบทความให้ลิงก์กลับ |
